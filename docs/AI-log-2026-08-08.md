## Session: quiz content and mandatory sign-in

Wrote all 200 questions: 10 chapters, 20 each (5 easy, 10 medium, 5 hard),
generated in parallel (one agent per chapter) from the book text in ~/books,
then a consistency and originality pass. Per the no-reproduced-sentences rule,
an 8-gram check flagged 57 verbatim overlaps across 29 questions; all were
rewritten and re-checked to zero. A `difficulty` field per question records the
mix. The seeder ignores unknown fields, so no schema change was needed for it.

Scope change from the initial build: sign-in is now MANDATORY to take a quiz
(previously open to everyone). New migration 20260808130000_require_signin.sql:
questions are readable only by authenticated users, submit_attempt() rejects
anonymous callers and always records the attempt, execute revoked from anon.
The client gates the Quiz page behind auth and updates the Home copy; the
quizzes catalog stays public so the landing page can still list chapters.

## Session: focus ring bug

Reported: a box appeared around the answer slot you picked on the previous
question. Cause was `key={i}` on the choice list. Same list length and shape
every question, so React reused the button nodes, the clicked one held focus,
and `*:focus-visible` in index.css drew the outline. State was correct
throughout; only the ring was stale.

Fix: key the question block by question id so it remounts, key choices by
question id plus index, and move focus to the prompt heading (tabIndex -1,
outline suppressed since the focus move is programmatic).

Verified by build only. No browser test was run in this environment.
